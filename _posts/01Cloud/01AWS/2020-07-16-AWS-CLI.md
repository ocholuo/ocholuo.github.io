## Using the AWS SDK for Python

The terminal also has Python 3 installed with the boto 3 library available.

to run AWS Python SDK code
```bash
$ python3
>>> import boto3
>>> ec2 = boto3.client('ec2', region_name='us-east-1')
>>> ec2.describe_regions()
>>> exit()
$
```
